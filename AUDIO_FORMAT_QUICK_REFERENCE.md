# Audio Format Quick Reference

## ✅ Fully Supported Formats

| Format | Extension | Quality | Best For | File Size |
|--------|-----------|---------|----------|-----------|
| **MP3** | `.mp3` | Lossy | General use | Small |
| **WAV** | `.wav` | Lossless | Studio quality | Large |
| **M4A/AAC** | `.m4a`, `.aac` | Lossy | iPhone/iPad | Medium |
| **FLAC** | `.flac` | Lossless | Archival | Medium |
| **OGG** | `.ogg`, `.opus` | Lossy | Web recordings | Small |
| **WebM** | `.webm` | Lossy | Browser recordings | Small |
| **AMR** | `.amr`, `.3gp` | Lossy | Phone calls | Very Small |

## 🎯 Quick Recommendations

### 📱 **Mobile Devices**
- iPhone/iPad: **M4A** or **AAC**
- Android: **MP3** or **OGG**

### 🎙️ **Professional Dictation**
- Best Quality: **WAV** or **FLAC**
- Good Balance: **MP3** (192+ kbps)

### 🌐 **Web Recordings**
- Chrome/Edge: **WebM**
- Firefox: **OGG**
- Safari: **M4A**

### 📞 **Phone/Telephony**
- Voice calls: **AMR**
- Recorded calls: **MP3**

## 📏 File Size Limits

- **Maximum**: 100 MB per file
- **Recommended**: Under 50 MB
- **Optimal**: 10-30 MB

## 🔧 Quick Troubleshooting

**File Rejected?**
1. ✅ Check format is in the list above
2. ✅ Verify file is under 100 MB
3. ✅ Try converting to MP3 or WAV
4. ✅ Test file in media player first

**Poor Transcription Quality?**
1. 📊 Use 16 kHz+ sample rate
2. 🎚️ Use 128 kbps+ bitrate
3. 🔇 Minimize background noise
4. 🗣️ Speak clearly and close to mic

## 💡 Pro Tips

- **Batch Upload**: Upload multiple files at once
- **Format Conversion**: Use Audacity (free) if needed
- **Backup Original**: Keep WAV/FLAC originals, share MP3
- **Optimize Size**: MP3 at 192 kbps is the sweet spot
