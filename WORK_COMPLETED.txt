   - App cannot authenticate to Supabase database

✅ 406 Error on user_profiles REST API
   - Client-side ANON key lacks SELECT permission on user_profiles table
   - CORS/Headers issue from Kong/Supabase

✅ 401 Error on /api/dashboard/stats
   - Missing Authorization Bearer token from client
   - API endpoint requires JWT for authentication
